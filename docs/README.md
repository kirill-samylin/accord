## Рабочая веб-версия (19.10.2026)

Текущее завершённое поручение: [TASK-004](TASK-004-human-web.md).
[Инструкция для человека](web-guide.md): вход, вопросы и ответы, задачи,
загрузка дизайна и история решений. [Подключение второго ПК](second-pc.md) и
[передача агенту](receiver-agent.md). Веб работает через обычный HTTPS с отдельными
токенами; точный адрес и приватные файлы передаются вне Git.
Фактические проверки/версия выпуска и ограничения указаны в TASK-004/WORK-094;
старые статусы исходного пилота не являются текущим статусом веб-выпуска.
