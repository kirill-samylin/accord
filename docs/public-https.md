# Accord: обычное подключение через HTTPS

Актуальный порядок от 19.10.2026: компьютер подключается к Accord через интернет,
по HTTPS и своему токену. Устанавливать Tailscale для этого подключения не нужно.
Инструкция заменяет прежние клиентские шаги с частным адресом и портом 8443.
Фактический результат развёртывания и проверенную версию см. в
[TASK-003](TASK-003-working-service.md): наличие инструкции само по себе не PASS.

## Если вы уже получили пакет Accord

1. Получите у администратора **обновлённый `connection.json`**. В поле `origin`
   указан новый HTTPS-адрес; не используйте адрес из старой переписки.
2. Сохраните свой прежний `pc-2.token`. Для смены адреса перевыпуск токена
   не требуется; если он истёк или отозван, новый выдаёт администратор.
3. Откройте в браузере адрес из `origin`, добавив `/readyz`. Ожидается HTTP 200
   с действительным сертификатом. Вход в Tailscale и корпоративная сеть не нужны.
4. В локальном MCP-конфиге Codex найдите `[mcp_servers.accord_worker]` и замените
   **только адрес после `--server`** на точное значение нового `origin`.
   Существующие абсолютные пути к клиенту и токену сохраните.
5. Перезапустите локальный Codex и выполните проверку ниже.

Клиент `agent-board` версии `1e9025c` подходит; пересобирать его и устанавливать
Go не нужно. Сам клиент **не читает `connection.json` автоматически**:
переданный файл содержит адрес для настройки аргумента `--server`.
Замена JSON без изменения MCP-конфига оставит старое подключение.

Пример macOS/Linux; адрес-заглушку и пути замените:

```toml
[mcp_servers.accord_worker]
command = "/ABSOLUTE/PATH/accord-client/agent-board"
args = ["mcp", "--server", "https://ACCORD_ADDRESS", "--token-file", "/ABSOLUTE/PRIVATE/PATH/pc-2.token"]
required = true
```

`https://ACCORD_ADDRESS` — только пример, действительный адрес берётся из JSON.
Выданный адрес может содержать IPv4: используйте его точно, с обычной проверкой
TLS. Домен для клиента не требуется. Не добавляйте `/mcp` к `--server`.
На POSIX приватный каталог имеет права 0700, токен — 0600.
В TOML записывается путь к токену, никогда его содержимое.

На Windows сохраните прежний раздел с `env_vars = ["AGENT_BOARD_TOKEN"]`,
замените адрес в `args` и запускайте новый Codex CLI из подготовленного
PowerShell с токеном, прочитанным из защищённого файла:

```powershell
$AccordPrivate = Join-Path $env:USERPROFILE '.config\accord'
$env:AGENT_BOARD_TOKEN = (Get-Content -Raw "$AccordPrivate\pc-2.token").Trim()
try { codex } finally { Remove-Item Env:AGENT_BOARD_TOKEN -ErrorAction SilentlyContinue }
```

Уже открытый GUI не получает окружение нового терминала. Не вставляйте токен
в TOML, literal `--env`, профиль оболочки или чат; не печатайте окружение.
Для нового компьютера и защиты Windows-файла — [second-pc.md](second-pc.md).
Настройки Codex: [официальная документация](https://learn.chatgpt.com/docs/extend/mcp).

## Проверка именно с этого компьютера

В локальном Codex проверьте запись через `codex mcp list`, затем доступность
Accord в `/mcp`. Запись в конфиге ещё не доказывает сетевое подключение.
Поручите агенту выполнить:

> Используй Accord. Прочитай новые параметры из локального connection.json;
> не печатай токен. Проверь TLS/readiness, MCP initialize и tools/list.
> Ожидаются 12 инструментов: comment, create, describe, events, get, heartbeat,
> link, next, note, release, transition, update. Вызови describe с
> role=coordinator, machine=pc-2 и новыми уникальными run_id/request_id.
> Создай свой epic «TEST pc-2 public HTTPS» с description, role="", priority=2
> и новым request_id. Прочитай выданный ключ через get и events
> (since_cursor=0, limit=100). Отмени только этот epic через transition
> (generation=0, state=cancelled, reason="synthetic cleanup", новый request_id).
> Все required-поля бери из tools/list. Сообщи ОС, SHA клиента, статусы,
> ключ и next_cursor без секретов. Заверши свой отдельный worker.

Если метка токена другая, `machine` должна совпасть с ней. Через worker
session_id подставляется автоматически. Один worker обслуживает одну роль
и один запуск: не раздавайте его независимым параллельным исполнителям.
После остановки heartbeat сессия истекает по TTL; публичного session close нет.
Чужие задачи и аренды для проверки не изменяются. Совместный тест двух
физических компьютеров выполняется отдельно; два процесса на Mac его не заменяют.

## Если возникла ошибка

| Признак | Что проверить |
| --- | --- |
| Timeout или TLS error | Точное значение нового origin, интернет, дату/время ПК; сертификат проверяет администратор |
| Старый адрес или порт 8443 | Заменён ли `--server`, сохранён ли конфиг и перезапущен ли локальный Codex |
| HTTPS 401 | Файл нужной машины, срок и отзыв токена; нужен действующий отдельный токен |
| Readiness 200, MCP 403 | Администратор сверяет Host/Origin и публичный reverse proxy |
| Нет инструмента Accord | MCP настроен в локальном приложении, где работает агент; одного Git clone недостаточно |
| machine mismatch | `describe.machine` совпадает с меткой выданного токена |
| LEASE_UNCERTAIN/LEASE_LOST | Остановить локальные изменения, переподключиться и сверить владение |

Не отключайте проверку TLS и не используйте `-k`/`--insecure`. Не запускайте
локальный `serve` и не подключайте Tandem. Старые частные маршруты сервера
не нужно менять на клиенте; публичное подключение Accord от них не зависит.
Физический Windows runtime и второй ПК остаются NOT-RUN до их проверки.
