## Сценарии и повторение

`check.py` читает публичный IPv4 из локального prerequisites и приватные токены только в памяти. Никакие значения токенов, Authorization-заголовки, сырой describe или содержимое доски в evidence не сохраняются. Адрес не зашит в тест и не публикуется в evidence. Запуск: `python3 /private/tmp/accord-public-078/qa/check.py`. Скрипт mutates ровно один новый synthetic epic под Mac-токеном, отменяет его в finally; повтор требует нового изолированного прогона и создаст новый cancelled epic. Не является нагрузочным SLA-тестом.

1. Зафиксировать текущее состояние Tailscale без переключения; готовность публичного origin и TLS с системной проверкой цепочки и IP SAN.
2. MCP initialize: отсутствующий/невалидный токен → 401; оба отдельных действующих токена → 200.
3. Реальный native stdio bridge под токеном pc-2: initialize, initialized notification, tools/list с точным каталогом 12. Без describe/session/mutations pc-2.
4. Реальный native stdio bridge Mac: свежая coordinator session; новый TEST epic; get и отфильтрованные events; отмена именно созданного epic с generation 0 и проверкой get. Завершить процесс bridge.
5. HTTP guards: чужой/loopback/неправильный port Host, absolute request URI с чужой authority → разрыв 444; чужой/null/фактически присутствующий пустой Origin → 403; Forwarded spoof не снимает Origin guard; body 65537 bytes → 413; public metrics и HTTP80 MCP → 404.
6. Последним: ровно 80 запросов к статическому ACME HTTP80 пути с concurrency16; без обращения к backend. Зафиксировать 429 и Retry-After: 1.
