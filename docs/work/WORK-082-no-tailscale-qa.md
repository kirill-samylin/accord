# WORK-082 — focused no-VPN retest

Роль: независимый тестировщик. Профиль tester и общий процесс прочитаны.
Именованные привязки моделей Claude недоступны; используется унаследованная модель.

## Граница

Создан standalone `scriptnovpn.py`, Python stdlib. Исполнитель не меняет состояние
Tailscale, сервер, Git, проект или доску. Оператор-координатор временно останавливает
Tailscale, запускает скрипт и восстанавливает исходное состояние в `finally`.

Скрипт сначала требует локальный `BackendState=Stopped`. Затем проверяет публичный
HTTPS по реальному глобальному IPv4 VPS из локального prerequisites.json: доверенная
системная цепочка TLS и соответствие IP сертификату, readyz=200, MCP initialize с
отдельным pc-2 токеном. Последние две проверки проходят через настоящий готовый
stdio-клиент: initialize и точный каталог 12 инструментов. Никаких tools/call,
describe, сессий доски, heartbeat или синтетических задач.

Токен читается только в память; raw body, адрес/IP, окружение и stderr клиента
в доказательства не записываются. JSON содержит статусы, тип ошибки, версию TLS,
SHA-256 сертификата и клиента, число инструментов. Общий alarm=50s, cleanup≤4s.
При FAIL скрипт возвращает ненулевой код. Это проверка с основного Mac без VPN,
не физическая приёмка второго ПК. Предыдущие доказательства QA081 не изменены.

## Передача

Статическая проверка синтаксиса: PASS. Сетевой запуск тестировщиком: NOT-RUN,
поскольку только координатор уполномочен временно менять состояние Tailscale.
Ожидаемый артефакт запуска: `no-vpn/result.json`; фактический статус результата
фиксирует координатор после запуска. Требуется независимое ревью нового скрипта.
