# WORK298 — два gennadiy на двух Mac, одна доска

Протокол эксперимента 26.10.2026 по поручению пользователя. **PREPARED /
прогон NOT-RUN**. Цель: проверить, что два интерактивных gennadiy (корпоративный
fork OpenCode) на двух разных Mac с двумя разными учётками Accord совместно
выполняют задачи одного репозитория, не беря чужие задачи и не ломая друг друга.
Это интерактивный режим через MCP-мост `agent-board mcp` (WORK297 `connect`),
не managed worker TASK013.

## Подключение второго Mac

1. Скачать клиент `agent-board` (macOS arm64) из релиза origin или собрать из
   `codex/native-preflight` (`make build`). Проверить `agent-board --help`.
2. Получить от администратора токен и `connection.json`; положить рядом в
   приватный каталог (0700/0600).
3. `agent-board connect --token-file /ABSOLUTE/PRIVATE/<file>.token` — команда
   сама пропишет MCP-сервер `accord` в gennadiy (и Codex/Claude, если есть).
4. `gennadiy mcp list` → `accord connected`; `gennadiy status` → вход действителен.
5. `git clone https://github.com/DenisShagi/js-tasks` и `npm test` (ожидаемо
   красный на заглушках).

## Ход прогона

Порядок: оба агента одновременно получают одну и ту же инструкцию:
«возьми следующую задачу через accord, выполни по README и AGENTS.md, открой PR,
отметь задачу выполненной». Человек сливает PR и отвечает на вопросы доски.
Сценарии D14/D16/D17 запускаются по сигналу человека в середине прогона.

Результаты (PASS/FAIL/NOT-RUN по строкам таблицы), SHA слитых PR, ключи задач
и наблюдения записываются сюда после прогона; токены, `connection.json` и
полные transcript'ы не публикуются.
