# Реальный Codex MCP — проверка на Mac

18.10.2026. Проверял координатор TASK-002 на текущем Mac, отдельно от SDK-тестов.
Codex CLI из установленного приложения: `0.163.0-alpha.10.2`, ChatGPT login.
ОС: macOS27.0.1 / arm64; сервер — локальный `bin/agent-board` после WORK-015.

## Результат

**PASS, четыре реальных MCP-вызова:** `describe` → `create` epic → `get` →
`events`. Все четыре завершились без client/tool error; создан синтетический
E-1, прочитан тот же E-1, `next_cursor=2`. Проверен фактический JSONL клиента,
а не только его итоговый текст. Сервер и клиент — отдельные процессы.

Использованы отдельная временная SQLite-БД, синтетический участник/токен,
случайный свободный loopback-порт и режим клиента read-only для файлов.
Токен передан дочернему процессу через переменную окружения из приватного файла;
он не включён в prompt, аргументы, отчёт или Git. Подключён только тестовый
Accord через настройки одного запуска `--ignore-user-config --ephemeral`.
Глобальный Codex config и реальная доска не менялись. После теста сервер
завершён по SIGTERM; тестовый токен отозван локально.

## Что было исправлено и повторено

1. На исходном21cb3e0 реальный клиент получал HTTP400 на initialized:
   сервер разрешал только2026-07-28. WORK-015 добавила совместимый2025-11-25
   штатным `ServerOptions.SupportedProtocolVersions`, без смены SDK и
   самописного handshake. Регрессии покрывают обе версии.
2. Первый повтор уже подключился, но тестовый запуск был ошибочно настроен
   с `approval_policy=never`: изменяющий `describe` требовал разрешения и был
   отклонён клиентом. Это отдельный FAIL конфигурации стенда; tool не исполнился.
   Это не отказ автоматического reviewer и не новая ошибка сервера.
3. Финальный запуск использовал `approval_policy=on-request` и
   `approvals_reviewer=auto_review` только для ограниченного синтетического
   smoke. Четыре вызова выполнены успешно. Политики глобальных клиентов
   и требования разрешений в пользовательской инструкции не ослаблялись.

Настройки URL, bearer_token_env_var и approval options сверены с
[официальной документацией MCP Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)
и [справочником конфигурации](https://learn.chatgpt.com/docs/config-file/config-reference).
Поддерживаемые версии — штатный контракт
[официального SDK1.8.0](https://github.com/modelcontextprotocol/go-sdk/blob/v1.8.0/mcp/server.go).
