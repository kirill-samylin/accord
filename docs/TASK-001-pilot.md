## Инварианты для проверки

1. Конкурентный захват даёт ровно одного владельца.
2. Истёкшая аренда недействительна до sweep; прежнее поколение не может менять
   задачу после повторного захвата. Сервер не останавливает локальные процессы.
3. Повтор мутации с тем же ключом не создаёт дубли и повторные события.
4. Пагинация событий не пропускает непрочитанные записи.
5. Отрицательный результат проверки не удовлетворяет положительной зависимости;
   approve относится к конкретному актуальному коммиту.
6. Исполнитель сам захватывает работу. Координатор не передаёт чужую аренду.
7. Данные сохраняются после restart; секреты не попадают в журнал.
